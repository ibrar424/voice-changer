Make your first recording

  1. Install and open Voice Changer AI.
  2. Paste the server address and keep the default voice ID for your first test.
  3. Allow microphone access. Record 5–10 seconds, then tap Stop recording.
  4. Tap Convert voice, then Play converted audio.

Use audio you have permission to process. Audio is sent to the server and ElevenLabs for conversion.
